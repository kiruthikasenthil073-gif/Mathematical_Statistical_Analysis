# Mathematics Statistics Analysis for Data Science

**Project Overview**

This project focuses on applying mathematical and statistical concepts using Python to analyse business data and understand patterns, relationships, and probabilities.

The assignment demonstrates the practical implementation of Linear Algebra, Probability, and Descriptive Statistics using Python libraries such as NumPy, Pandas, SciPy, and Matplotlib.

**Objectives**

- Perform vector and matrix operations using NumPy.
  
- Calculate determinants, inverse matrices, eigenvalues, and eigenvectors.
  
- Understand basic probability and conditional probability.
  
- Apply Bayes' theorem to customer purchase analysis.
  
- Simulate binomial, normal, and uniform distributions.
  
- Calculate descriptive statistical measures.
  
- Analyse skewness and kurtosis to understand data distribution.
  
- Interpret statistical results for business decision-making.

**Key Findings**

- Vector and matrix operations were successfully performed.
  
- The determinant of Matrix A is -7, confirming that its inverse exists.
  
- The overall customer purchase probability is 69.5%, based on the given customer segment proportions.
  
- Bayes' theorem gives a probability of approximately 51.61%.
  
- The average sales value is 165.50.
  
- The median sales value is 165.
  
- The sales dataset is approximately symmetric with very little positive skewness.
  
- Negative kurtosis indicates a relatively flat distribution compared with a normal distribution.
